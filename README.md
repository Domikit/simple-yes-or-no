# Simple Yes/No Website

Open `index.html` in a browser to use the small app. Type a question and click **Ask** (or press Enter). The page will answer "Yes" or "No" with a tiny deterministic + random heuristic.

Files:
- index.html — main page
- style.css — styling
- script.js — interaction logic

To run locally, simply open the file in your browser or serve the folder with a simple static server. Example using Python 3:

```
python -m http.server 8000
# then open http://localhost:8000/simple_yes_no_site/
```
